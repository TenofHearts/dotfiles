Hyprland shortcuts

Alt + H/J/K/L focuses windows. Alt + 1-9 switches workspaces. Alt + Q closes the focused window.

ModeShortcutAction
Every modeAlt + Shift + ;Open Command mode
Every modeAlt + Shift + SSelect a region in Shotori. In the selection overlay: Ctrl + C copies, Ctrl + T pins, and Ctrl + S saves.
MoveShift + H/J/K/LMove the current workspace to the nearest monitor in that direction
CommandMMove mode
CommandRAdjust mode
CommandAAdmin mode
MoveH/J/K/LMove the focused window
Move1-9Move the focused window to a workspace and follow it
AdjustH/J/K/LResize the focused window by 25 pixels
AdjustFToggle fullscreen
AdjustT / WSet tiled / toggle floating
AdjustSpaceCycle this workspace: Dwindle, Scrolling, Master, Monocle
AdminRReload Hyprland configuration
AdminDForce a renderer redraw

Escape or Enter leaves any mode. In Command, press ? for this guide or Alt + Shift + ; to return to Normal.

Join, minimize, pause-management, and accordion bindings are intentionally unassigned because Hyprland has no loyal equivalent for them.
